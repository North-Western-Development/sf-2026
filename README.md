<p align="center">Your own communication network: communities, voice and video, and end-to-end encryption, on a server you run.</p>

## What it is

Subspace Frequency is a self-hosted chat and voice platform in the spirit of Discord, with its own vocabulary:

| Subspace | Means |
| :--- | :--- |
| Beacon | A community (server) |
| Relay | A channel: text, forum, gallery, announcement or voice |
| Comm-Link | A voice and video channel |
| Direct Link / Mesh | A direct message / group DM |
| Transmission | A message |
| Clearance | A role |

A public instance runs at [subspace.click](https://subspace.click), and the full documentation is at [docs.subspace.click](https://docs.subspace.click).

## Features

- **Communities:** beacons with text relays, forums, galleries, announcement relays other beacons can follow, roles with 64-bit permissions, invites, onboarding, bans, moderation and discovery.
- **Voice, video and screen share:** Comm-Links and direct calls on a [LiveKit](https://livekit.io) server you run, with ringing, missed calls, stages and soundboards.
- **End-to-end encryption:** direct links can turn on X3DH and Double Ratchet encryption, and encrypted calls encrypt every media frame in the browser.
- **Secure by default:** every route needs a session unless it is marked public; passkeys and authenticator two-factor sign-in; device sessions you can revoke instantly.
- **Privacy:** no analytics or tracking cookies, anonymized server logs, and mobile push that never passes through a third-party relay.
- **Clients:** the web app, a desktop app ([Tauri](https://tauri.app)) and an Android and iOS app ([Expo](https://expo.dev)).
- **A developer platform:** bots with slash commands and a real-time gateway, webhooks, Sign in with Subspace (OAuth2), Rich Presence and custom Activities, with SDKs for JavaScript, Deno, Python, Java, C#, C++, Unity and Unreal Engine.


## Run it locally

You need Node.js 22, pnpm 10, PostgreSQL 16+ and Redis 7+. MinIO (uploads) and LiveKit (voice) are optional. No Docker is required.

```bash
pnpm install
cp .env.example .env    # fill in every value marked REQUIRED
pnpm dev:native         # builds shared packages, applies migrations, starts everything
```

Then open http://localhost:5173. The [local development guide](apps/docs/guide/local-development.md) covers setting up the databases, including on Windows with WSL.

## Tests

```bash
pnpm test:native    # backend unit and end-to-end tests against a test database
pnpm test:ui        # browser tests (Playwright) on an isolated copy of the app
pnpm test:web       # web app unit tests
```

[Testing](apps/docs/reference/testing.md) lists every suite, including the live smoke tests against a deployed instance.

## Deploy your own

`deploy/server` installs a hardened, native instance on one Debian server: one system user per service, sandboxed systemd units, nginx with Let's Encrypt, LiveKit with TURN, and self-hosted push. Start with the [deployment guide](apps/docs/operate/deployment.md) and [deploy/server/README.md](deploy/server/README.md).
